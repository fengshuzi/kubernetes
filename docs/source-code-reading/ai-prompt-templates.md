# Kubernetes 源码阅读 AI 提问模板

## 🎯 为什么需要提示词模板

作为Java开发者学习K8s源码时，向AI提问的质量直接影响学习效率。好的提示词能让AI：
- 理解你的背景和当前水平
- 提供针对性的解答
- 给出可执行的代码示例
- 对比Java相关概念

## 📝 通用提示词模板

### 基础模板
```
我是一名有10年Java开发经验的工程师，正在学习Kubernetes源码。

【背景信息】
- 当前正在阅读：[具体文件路径/组件名]
- 我的Java背景：[Spring/微服务/分布式系统等]
- 当前理解程度：[初学者/有基础/深入学习]

【具体问题】
[你的问题]

【期望的回答】
- 请用Java开发者容易理解的方式解释
- 如果可能，请对比相关的Java概念或框架
- 提供具体的代码示例和注释
- 指出学习的重点和难点
```

## 💡 提问技巧总结

### ✅ 好的提问方式
1. **明确身份背景** - "作为Java开发者"
2. **具体问题描述** - 避免模糊的"如何学习"
3. **提供代码上下文** - 文件路径+行号
4. **期望回答格式** - 要代码示例还是概念解释
5. **对比学习需求** - 与Java概念对比

### ❌ 避免的提问方式
1. "K8s怎么学？" - 太宽泛
2. "这段代码什么意思？" - 缺少背景
3. "帮我写个Controller" - 需求不明确
4. "为什么报错？" - 缺少错误信息
5. "最佳实践是什么？" - 没有具体场景
